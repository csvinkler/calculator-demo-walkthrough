# Mini Calculator

A tiny web page published with GitHub Pages, used to show manual testing, unit testing and CI.

| ID | Requirement |
|---|---|
| REQ-01 | The first row shows the sum of the two numbers (a + b). |
| REQ-02 | The second row shows the difference of the two numbers (a - b). |

## Run the unit tests

- In the browser: open `tests/tests.html` (double-click the file, no install needed).
- In a terminal: `node tests/run-tests.js`
